# Footer

The dark site footer: wordmark and tagline, three link columns, a service-status line, and the legal row.

Mapped from the Coca-Cola `Footer` (black, 2fr/1fr/1fr grid) and Cicchetti's `.footer__grid` / `.footer__legal`. Vertex sets it on `inverse` with mono column headings.

## The consumer provides
The tagline, link groups (three or four, three to six links each), the live status text for `vx-status` (keep the words; the dot is decoration), and the legal line. Under 640px it becomes two columns with the brand row spanning both.
