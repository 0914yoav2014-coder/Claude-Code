# Credits and licences

Content-owned. Every third-party asset, where it came from, its licence, and how sure we are. "Confirmed" means we checked it ourselves (file, package metadata or the publisher's site); "stated" means we rely on a third party's description.

## Earth textures (`public/textures/earth/`)

Built by `scripts/assets/build-earth.sh`, which runs `scripts/assets/earth_textures.py`. The script downloads `three-globe@2.45.3` from npm into a temporary folder outside the repo. The tarball's sha256 is `e5266133038d181a3a7b372a14d8ca34675f7565a6db89201cc5118d790f040e`. It reads four images from `package/example/img/`. All outputs are equirectangular, with longitude −180 → 180 from left to right and north up.

- **three-globe** (© 2019 Vasco Asturiano) is MIT. We confirmed this from `package.json` (`"license": "MIT"`) and the `LICENSE` file in the 2.45.3 tarball. https://github.com/vasturiano/three-globe
- **NASA imagery.** Our source for the claim that the example images are NASA Blue Marble and Black Marble derivatives is the project contracts (CONTRACTS §11) and common knowledge of these widely reused files. The package itself does not say where they came from, and we did not trace each file back to a specific NASA product page. Under NASA's media guidelines, NASA imagery is generally not copyrighted. If in doubt, credit as "NASA Visible Earth". https://visibleearth.nasa.gov/ · https://www.nasa.gov/nasa-brand-center/images-and-media/
- **Not used:** `example/clouds/clouds.png` from three-globe, because its licence is unknown. The other example images are also unused (`earth-day.jpg`, `earth-dark.jpg`, `night-sky.png`).
- **WebP note:** WebP has no grayscale mode, so `clouds-2k.webp` and `water-1k.webp` are stored as RGB with R = G = B. Shaders should read `.r`.
