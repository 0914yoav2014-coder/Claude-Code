## Notes and questions
- three r186 quirk: RenderPass clears before render(), so the clear colour lands in the wrong colour space;
  fixed by `scene.background = navy`. Full navy frames are a plain clear (exact #0B1426).
- In `?test=1` the governor ignores real frame times (SwiftShader is slow); only `forceFrameTimes` feeds it.
- Under SwiftShader the real page (glass blur etc.) is very slow: Earth textures can take > 15 s to arrive in
  tests; the globe shows a dark-blue fallback until then.
- Run `scripts/capture.mjs` against a dev server without HMR (edits mid-capture reload the page); e.g. a
  second Vite on a spare port with `server.hmr=false, watch=null` (`--base http://localhost:<port>`).
- Auto-spin pauses while a route is selected (Frontend selects SITE.defaultRoute when the globe appears).
